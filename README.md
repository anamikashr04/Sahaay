# Sahaay Care System

Interactive mobile app prototype of the Sahaay Care System, a continuous care support system for St. Jude India ChildCare Centres.

**Team Sahaay** · ServDes India Student Service Design Competition 2026

## Roles in the prototype
- **Parent:** request aid, track requests, see kids' activities
- **Contributor:** support urgent needs and track impact
- **Volunteer:** onboard, get verified, propose workshops
- **Staff:** approvals, facility repairs, posting needs, evening handover and night alerts
- **Night Care:** parent support from 6 PM to 10 AM, when no staff are on site (alerts, guided steps, emergency contacts)

Open `index.html` in a browser, or view the live version on GitHub Pages.
